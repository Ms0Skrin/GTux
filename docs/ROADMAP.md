# План и состояние проекта

Обновляется в конце каждой рабочей сессии. Последнее обновление: **2026-10-26**, версия **0.2.0**.

## Сделано

**Проверки** (только чтение, 13 групп, 82 теста):
- Система: дистрибутив, ядро, пакетный менеджер (pacman / apt / dnf).
- Видеокарта: драйвер, версия NVIDIA/Mesa, рассинхрон после обновления, `nvidia_drm.modeset`, Resizable BAR.
- Vulkan: загрузчик, ICD, `vulkaninfo`.
- 32 бита: multilib / i386 / .i686, lib32-драйверы, версии NVIDIA 64/32.
- Steam: способ установки, библиотеки, доступ Flatpak-Steam к другим дискам.
- Диски: NTFS/exFAT, `windows_names`, вынесенный `compatdata`, ro, noexec, «грязный» NTFS, HDD, место.
- Proton: версии Valve, сторонние сборки, GE.
- Утилиты: gamemode, MangoHud, gamescope (+ 32-битные части на Arch).
- Настройки: governor (с EPP), `vm.max_map_count`, лимит файлов, `split_lock_mitigate`.
- Железо: ОЗУ и swap/zram, звук (PipeWire + pipewire-pulse), udev-правила геймпадов.
- Игры: Steam, Heroic (Epic/GOG/Amazon/sideload), Lutris, Faugus — чем запускается, удалённая сборка
  Proton, ошибки в параметрах запуска, античит (снимок AreWeAntiCheatYet + `games.toml`), требования.
- Логи Proton: недостающие DLL (+ protontricks), падение в Wine, VK_ERROR_DEVICE_LOST, сломанный префикс.

**Интерфейсы**: терминал (rich), `--json`, `--report` (Markdown для форума), окно GTK4/libadwaita
(пастельная тема, обзор, разделы, «Что изменилось», «Исправить…» через pkexec, конструктор
параметров запуска, переключение ru/en).

**Прочее**: `--fix` (установка пакетов с подтверждением), история проверок и diff, отладочный журнал
с ротацией, английский перевод, лицензия GPL-3.0-or-later, пакет pacman (`scripts/build_arch_package.sh`),
`pyproject.toml` для pipx, ярлык в меню (иконка — временная заглушка), пакет 0.2.0-2 установлен у Евгения, строка статуса Claude Code в `~/.claude/statusline.py`
(лимиты 5ч/неделя Claude Code присылает устаревшими — помечаем «лимиты от …»).

## Известные ограничения
- Heroic/Lutris/Faugus проверены только на тестовых конфигах (у Евгения в них пока нет игр).
- apt/dnf проверены тестами с имитацией `dpkg-query`/`rpm`, на живых системах — нет.
- Диалог «Исправить…» не снимается на Broadway (на скриншоте — снимок с реального экрана, демо-данные);
  реальная установка через окно ещё ни разу не запускалась.
- Окно на очень узком экране (сворачивание боковой панели) глазами не проверялось.

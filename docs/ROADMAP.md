# План и состояние проекта

Обновляется в конце каждой рабочей сессии. Последнее обновление: **2026-10-26**, версия **0.6.0**. Название приложения — **GTux**.

## Сделано

**Проверки** (только чтение, 14 групп, 112 тестов):
- Система: дистрибутив, ядро, пакетный менеджер (pacman / apt / dnf).
- Видеокарта: драйвер, версия NVIDIA/Mesa, рассинхрон после обновления, `nvidia_drm.modeset`, Resizable BAR.
- Vulkan: загрузчик, ICD, `vulkaninfo`.
- 32 бита: multilib / i386 / .i686, lib32-драйверы, версии NVIDIA 64/32.
- Steam: способ установки, библиотеки, доступ Flatpak-Steam к другим дискам.
- Диски: NTFS/exFAT, `windows_names`, вынесенный `compatdata`, ro, noexec, «грязный» NTFS, HDD, место.
- Proton: версии Valve, сторонние сборки, GE.
- Утилиты: gamemode, MangoHud, gamescope (+ 32-битные части на Arch).
- Настройки: governor (с EPP), `vm.max_map_count`, лимит файлов, `split_lock_mitigate`.
- Железо: ОЗУ и swap/zram, звук (PipeWire + pipewire-pulse), udev-правила геймпадов.
- Игры: Steam, Heroic (Epic/GOG/Amazon/sideload), Lutris, Faugus — чем запускается, удалённая сборка
  Proton, ошибки в параметрах запуска, античит (снимок AreWeAntiCheatYet + `games.toml`), требования.
- Логи Proton: недостающие DLL (+ protontricks), падение в Wine, VK_ERROR_DEVICE_LOST, сломанный префикс.

**Интерфейсы**: терминал (rich), `--json`, `--report` (Markdown для форума), окно GTK4/libadwaita
(пастельная тема, обзор, разделы, «Что изменилось», «Исправить…» через pkexec, конструктор
параметров запуска, переключение ru/en).

**Исправление одной кнопкой** (`--fix` и «Исправить…» в окне): пакеты, i386 на Debian/Ubuntu, настройки ядра в `/etc/sysctl.d` (max_map_count, split_lock), доступ Flatpak-Steam к папкам. Проверка объявляет это через `actions=[Action(...)]`, в окне можно снять галочки, всё с root выполняется одним pkexec, после исправления программа проверяет систему заново.

**Параметры запуска под ПК**: на странице «Параметры запуска» выбирается игра Steam → переключатели
по её текущей строке, советы игроков ProtonDB под этот ПК (видеокарта, Wayland, сборка Proton игры, установленные
обёртки; белый список документированных переменных), «Записать в Steam» (`gtux/steamcfg.py`: точечная
правка localconfig.vdf, только при закрытом Steam, копия + журнал, «Вернуть как было»).
База знаний: `gtux/knowledge.py`, `--update-kb` / меню; выгрузка bdefore/protondb-data (ODbL, ~70 МБ,
докачка при обрыве) + оценки с неофициального API protondb.com → `~/.cache/gtux/knowledge.json`.
В проверке игр — строка с оценкой ProtonDB и советами.

**Рекомендация сборки Proton** (0.4.0): на странице «Параметры запуска» блок «Рекомендация для вашего ПК» —
лучшая сборка у игроков с такой же видеокартой за последний год (`knowledge.proton_for`, интервал Уилсона,
из почти равных — самая простая), установлена ли она (`installed_variants`), выбрана ли уже, как выбрать в Steam,
остальные сборки со счётом, итог по параметрам. Та же строка в проверке игр и отчёте. База знаний версии 2
(старую нужно обновить — окно об этом говорит).

**Рискованные исправления «по желанию»** (сняты по умолчанию, с предупреждением): включение [multilib]
(`sed` только по строкам раздела, сверка SHA-256 файла перед правкой, копия `pacman.conf.gtux-<время>`,
затем `pacman -Syu` и пропущенные lib32-пакеты), `pacman -Syu` при рассинхроне NVIDIA 64/32,
`protontricks <appid> -q <пакеты>` для недостающих DLL из логов. Параметры ядра (modeset) — только вручную.

**Переименование в GTux** (0.5.0): Python-пакет `gtux`, команда `gtux`, application id `io.github.Ms0Skrin.GTux` (по аккаунту GitHub),
пакет pacman `gtux` (заменяет `linux-gamer-doctor`: conflicts/replaces), папки `~/.cache|.local/state|.config/gtux`
(`gtux/paths.py` один раз переносит старые `linux-gamer-doctor`), журнал `gtux.log`, переменные `GTUX_GUI_*`.
**Лаунчеры и «по желанию»** (0.6.0): группа «Лаунчеры и помощники» (Heroic, Lutris, Faugus, protontricks);
в плане исправлений — `plan.offers` с снятыми галочками: Lutris/protontricks пакетом, Heroic/Faugus с Flathub
(`--user`, flatpak ставится тем же шагом), GE-Proton — `gtux --install-ge DIR` (GitHub, SHA-512, проверено вживую
на GE-Proton11-11). В окне root-шаги идут первыми одним pkexec, потом шаги без пароля.
Сверка имён пакетов 2026-10-26: Arch (pacman -Si), Debian 13, Ubuntu 26.04 (Launchpad), Fedora (mdapi), Flathub.
Найдено и исправлено: на Arch `steam`/`steam-devices` в multilib, на Debian/Ubuntu `steam-installer` требует i386.
GTK4/libadwaita/PyGObject — обязательные зависимости пакета.

Репозиторий: https://github.com/Ms0Skrin/GTux (ветка main). В коммитах и PKGBUILD — скрытая почта GitHub (noreply).

## Известные ограничения
- Запись в Steam проверена тестами и на копии настоящего localconfig.vdf; при закрытом Steam вживую
  ещё не запускалась (Steam был открыт). Используется только первый найденный Steam (обычный или Flatpak).
- Разбор выгрузки ProtonDB занимает 1–2 минуты процессора (390 тыс. отчётов, потоково, ~50 МБ памяти).
- Советы — статистика по отчётам игроков, а не проверенные исправления; переменные только для GE-Proton/proton-cachyos помечаются по сборке игры.
- Heroic/Lutris/Faugus проверены только на тестовых конфигах (у Евгения в них пока нет игр).
- apt/dnf проверены тестами с имитацией `dpkg-query`/`rpm`, на живых системах — нет.
- Диалог «Исправить…» не снимается на Broadway (на скриншоте — снимок с реального экрана, демо-данные);
  реальная установка через окно ещё ни разу не запускалась (с pkexec и одним паролем на всё — тоже).
- Окно на очень узком экране (сворачивание боковой панели) глазами не проверялось.
- Рекомендация сборки: proton-cachyos в ProtonDB не выделяется (попадает в notListed, его не считаем);
  «официальный» = текущий стабильный Proton на момент отчёта. Linux-версию игры определяем по games.toml
  и AreWeAntiCheatYet — для игр вне этих баз текущей считается сборка Steam по умолчанию.
- GE-Proton предлагается только когда его нет совсем; обновление до свежего релиза — пока вручную (`gtux --install-ge`).
  Ставится в первый найденный Steam. Пакеты RPM Fusion (Fedora) автоматически не сверялись.
